# Hindsight

Hindsighting mod for Slay the Spire 2 akin to run resumer from StS1

## Installing

Download the latest zip from https://github.com/Landmaster/Hindsight/releases and unzip the contents in the mods directory of Slay the Spire 2. Requires [BaseLib](https://github.com/Alchyr/BaseLib-StS2)

## Usage

Click on a run node in run history and it will prompt you if you want to replay that run from that floor (nothing will be saved). By default the last 5 runs will have data kept so that they can be replayed in this manner; this can be adjusted in the config.
