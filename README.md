# Hindsight

Hindsighting mod for Slay the Spire 2 akin to run resumer from StS1

## Installing

Download the latest zip from https://github.com/Landmaster/Hindsight/releases and unzip the contents in the mods directory of Slay the Spire 2. Requires [BaseLib](https://github.com/Alchyr/BaseLib-StS2)
